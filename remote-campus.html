Operating principles — all remote campuses

🔍 Read-only by default

Monitoring never changes a device. Patrols, readiness sweeps, log captures and watchdogs only observe; any action on a device follows the approval rules of the site SOP.

🧭 Evidence in a fixed order

Faults are judged on the AV-over-IP evidence first, PTZ camera views in support, and the monitoring snapshot data to corroborate — never on a single signal.

✋ Human approval gate

Resets, power cycles and control presses wait for the site owner's confirmation, except for the small number of standing authorisations written into the SOP (for example the morning TV-on run).

🗂️ Scheduled and logged

Every routine check runs on a published schedule and produces a report, so the state of each room is reconstructable afterwards — what was seen, what was decided, and what was done.

Remote Campus is part of the Support Portal. Operational detail in each campus SOP reflects the live configuration agreed with the site owner; procedures change only through the document-control process at the end of each SOP.
